Entry for the make.fun bounty [Sum up 25 November's world news in one image](https://make.fun/bounty/news-image-20261125).

`main.py` (Python standard library only) draws a one-page broadsheet of Wednesday 25 November 2026 — three hero stories (Hormuz tanker mines, US tariffs on 14 economies, Shenzhou-24 with Pakistan's first astronaut), a markets strip, 32 short news cards and an in-brief ticker — and writes it to `/output/entry.png` (1024×1024 PNG, deterministic, no network).

Run locally:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
